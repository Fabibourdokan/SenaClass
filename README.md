# 📚 Sistema de Agendamento de Salas

Sistema web desenvolvido para facilitar o **gerenciamento e agendamento de salas de aula**, permitindo visualizar a disponibilidade dos ambientes e a grade de aulas durante a semana.

## 🎯 Objetivo

O projeto tem como objetivo desenvolver uma interface simples e intuitiva para organizar o uso das salas, evitando conflitos de horários e facilitando a visualização dos agendamentos.

## 🚀 Funcionalidades

* 📊 Dashboard com visão geral do sistema
* 🏫 Visualização das salas disponíveis
* 🟢 Status das salas: Livre ou Ocupado
* 📅 Grade semanal de aulas
* 🕐 Organização por períodos:

  * Manhã: 08:00 às 12:00
  * Tarde: 13:30 às 17:30
  * Noite: 19:00 às 22:30
* 👥 Informações sobre capacidade das salas
* 💻 Visualização dos equipamentos disponíveis
* 📋 Visualização dos agendamentos
* 🔎 Filtros por sala e período

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 💻 Interface

O sistema possui uma interface administrativa com menu lateral, dashboard, cards de status das salas e calendário semanal para facilitar a visualização dos horários.

## 📌 Status do projeto

🚧 **Em desenvolvimento**
